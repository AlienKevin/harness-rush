Harness Rush / Codex Release Cadence

Every stable release of @openai/codex, from npm publish timestamps and GitHub release notes (also published at developers.openai.com). Alpha builds are excluded. CLI releases only: the IDE extension, Codex Web, and Codex in the ChatGPT app ship separately and are not counted. A picture of how fast an AI coding agent ships.
